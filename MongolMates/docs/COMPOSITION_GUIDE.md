# 构图规范 COMPOSITION_GUIDE

构图类型枚举（`composition`）：`bust`（半身）、`full_body`（全身）、`seated`（坐姿）、`scene`（场景）。

## 半身人物（bust）

- 保留原头部大小、肩膀和手臂原始比例、手势和手部位置。
- 只延续必要的一小段衣服；根据原衣服的袖子、腰部、褶皱方向自然补画。
- 衣服左右宽度与上半身协调，可轻微收窄，不应突然外扩；最终自然贴近底边。
- 例：「啊？！」为弟弟惊讶半身特写，双拳放胸前。不需画腿、鞋或完整下半身；蓝袍在腰部以下自然补充极少量衣料。

## 坐姿人物（seated）

以「我想静静…」为例，必须清晰区分六层：
1. 手掌与手指 2. 袖子 3. 袖口 4. 衣服主体 5. 膝盖或裤腿 6. 鞋子。

- 手必须有明确肤色，不能与袖口或衣服混成一体。
- 袖口应有明确黄色装饰区域。
- 衣服主体通过轮廓、层次、褶皱区分。
- 坐姿符合人体结构与透视，不得出现难以解释的绿色或棕色区域。
- **不得回退到手、袖子、衣服混在一起的旧版本。**

## 动态人物（full_body）

以「我先溜了！」为例：保留完整动态结构；不强行贴底；不拉伸鞋子、腿或衣服；保留动作线和烟团；动作方向与重心自然。

## 场景（scene）

以「你才是挑战者哦！」（漫画放射线背景）、「路上小心！」（草原骑马）、「那达慕！」（蒙古包/装饰）为例：保留完整环境关系与背景，按 `white_scene` 处理，不强行删除背景。

## 文字与排版差异

- 日常篇多数：人物上方或中间、中文位于下方。
- 嘴替篇多数：中文位于上方、人物位于中下部。
- 情绪篇：按已审核原图保留对应构图。

**不要将三套表情强制转换成完全相同的文字位置。**
