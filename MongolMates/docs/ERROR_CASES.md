# 错误案例 ERROR_CASES

用于避免重蹈覆辙的真实风险清单（与初始审计发现对应）。

## 资产类

| 错误 | 后果 | 正确做法 |
| --- | --- | --- |
| 用低清 240px 放大成 1200px 当 `original` | 虚假高清交付 | 记录真实 source_resolution，标记 `missing_native_master`，拒绝正式发布 |
| 仅凭文件名 `final`/`v2`/`fixed` 判断最终版 | 用回有缺陷的旧图 | 逐张人工确认，尤其反复改过的「啊？！」「我想静静…」「吃瓜中～」 |
| 把英文标识当已核实中文文案 | 文案错误 | 情绪篇须读原图登记真实中文 |
| 用网上蒙古族卡通图当官方素材 | 角色不一致 | 只用本项目确认母版 |
| 不同角色图片互相替代 | 身份错乱 | 按 character ID 严格对应 |

## 结构类

| 错误 | 后果 | 正确做法 |
| --- | --- | --- |
| 复制最后一行像素补衣服 | 假底边、结构失真 | 自然补画少量衣料，保持上身宽度 |
| 垂直拉长衣服/衣摆加宽 | 比例失真 | 只延续必要一小段，可轻微收窄 |
| 坐姿手、袖、衣服混在一起 | 人体结构错误 | 六层清晰区分（见 COMPOSITION_GUIDE） |
| 背面随意加斜向装饰 | 违背母版 | 遵守具体母版背部纹样 |
| 帽缨无故放大 | 头饰变形 | 保持母版比例 |

## 角色特征类

- 爸爸被画成没胡子的青年。
- 妈妈头巾被换成姐姐的尖顶帽；姐姐帽顶被画成蝴蝶结。
- 姐姐侧面被强行加第二根辫子（应只画视角可见的一根）。
- 弟弟升级/背面视角时衣服背部乱加装饰。

## 背景类

- 把漫画放射线白底强行抠成透明（「你才是挑战者哦！」应保留白底）。
- 抠图误删眼白、牙齿、高光、气团/云朵内部白色、袖口白装饰。
- 气团只画空心线条，未做纯白不透明填充。
- 预览时把背景色烘焙进透明 PNG 母版。
- 白边宽度在 240px 与 1200px 之间不换算，导致同系列观感不一。

## 文字与交付类

- 把艺术字替换成普通系统字体；擅自改字或标点。
- 三套系列被统一成同一文字排版位置。
- 正式 ZIP 混入未修改图或多个系列；仅输出文件路径而无下载链接。
- 缺母版却宣称“已完成”。
