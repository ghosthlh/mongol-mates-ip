# 图片修复规则 IMAGE_EDITING_RULES

修复优先采用**精确局部修改**，而不是整张重画。

## 身体/服装底部（强制）

**核心原则：自然补画身体，不拉伸已有身体。** 若原图为半身，必须继续保留半身构图。

允许：为贴近画布底边，在衣服下方补画少量自然延续的结构。

禁止：
- 复制最后一行像素。
- 将衣服垂直拉长。
- 使用大面积单色块填充底部。
- 将衣摆无故加宽。
- 把半身人物改成全身人物。
- 添加与原动作无关的腿和鞋。
- 用简单矩形或梯形代替自然衣服结构。

> 若无法通过自动图像处理可靠完成自然身体补画，应采用真正的局部重绘流程，或标记需要人工绘制。**严禁使用复制像素行、拉长底边或简单色块填充伪装完成结构修复。**

## 七步修复流程

1. **读取待修图片及对应母版**，明确用户指出的问题区域。
2. **建立修改范围**：如“只修衣服下摆”，范围限制在下摆及必要自然连接区域。
3. **保留其余已确认内容**：不改眼睛、帽子、脸型、文字、姿势。
4. **采用正确修复方法**：透明背景清理 / 描边修复 / 局部遮罩 / 局部重绘 / 身体结构补画 / 文字修正 / 道具局部修正。
5. **生成对比预览**：至少提供原始版、修复版、深色背景效果、浅色背景效果。
6. **执行质量检查**：确认目标问题改善且未引入新问题。
7. **用户确认**：只有确认后才更新正式母版。

确认后：生成两个尺寸 → 只打包当前修改文件（package_patch.py）。

## 修改范围纪律

若用户只要求修改衣服底部，必须只修改对应区域，不得顺便更换眼睛、头饰、文字、肤色、表情、道具、其他服装纹样。若技术上无法完全保留其他区域，应在预览中明确说明可能变化，不得声称完全一致。

## 版本与审批

每次重要修正保留：之前的正式版本、当前候选修正版、修改内容、修改原因、审核状态、相关源文件。

命名示例：`Vol03_11_我想静静_v1.0.png` → `v1.1` → `v1.2`。不在同一文件名下反复覆盖历史定稿。审核状态流转：working → candidate → approved（仅用户确认）。
