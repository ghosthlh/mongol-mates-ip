# IP 概览 IP_OVERVIEW

- **项目名称**：蒙古萌友（Mongol Mates）
- **规范版本**：v1.0
- **项目类型**：原创角色 IP / 微信静态表情包
- **管理目标**：跨 AI 一致性、原生高清资产、局部可控修复、自动检查、规范交付

## 固定角色

爸爸（father）、妈妈（mother）、姐姐（sister）、弟弟（brother）四位家庭成员。身份与核心视觉特征固定，详见 `CHARACTER_BIBLE.md` 与 `config/characters.yaml`。

## 三套系列

| 系列 ID | 名称 | 数量 | 说明 |
| --- | --- | --- | --- |
| `vol01_daily` | 日常篇 | 16 | 日常问候语；含骑马草原、那达慕等复杂场景 |
| `vol02_emotions` | 情绪篇 | 16 | 四角色各 4 种情绪；现有资产仅有英文标识，真实中文待读图登记 |
| `vol03_reactions` | 嘴替篇 | 16 | 网络口语化表达；含漫画放射线背景（保留白底）等复杂场景 |

##  serie 内容索引

### 日常篇 vol01_daily

你好！/ 在吗？/ 来啦！/ 兄弟！/ 好！/ 行！/ 对！/ 不！/ 谢谢！/ 对不起！/ 没关系！/ 哈哈哈！/ 晚安！/ 路上小心！/ 拜拜！/ 那达慕！

其中「路上小心！」（骑马草原）、「那达慕！」（蒙古包/场景装饰）按复杂场景规则处理。

## 可变化 / 不可变化

可变化：表情、动作、手势、道具、场景、文字、构图。

不可随意变化：角色身份、核心头饰、发型、辫子结构、胡子、基础服装与颜色、正常眼睛视觉特征、整体画风。
