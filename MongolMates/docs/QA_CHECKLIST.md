# 质量检查清单 QA_CHECKLIST

## 技术检查（可自动）

- 文件存在、可解码、格式为 PNG。
- 图片尺寸、Alpha 通道、文件大小。
- 异常矩形边框、四角残余白底、透明区域散落杂点。
- 过长水平/垂直残留线、完全透明却带异常 RGB 的区域。
- ZIP 完整性；原图与导出图元数据一致。
- 边缘检查对复杂场景做例外，不把白底误判为错误。
- 连续相同像素行/重复纹理 → 提示历史拉伸风险（仅风险警告，不据此宣称结构正确）。

对应工具：`validate_image.py`、`check_transparency.py`、`verify_zip.py`、`validate_character_metadata.py`、`audit_assets.py`。

## 视觉检查（人工或视觉模型辅助）

- 四角色身份正确；头饰正确；辫子数量正确。
- 眼睛高光符合表情；胡子结构正确；手指数量正确。
- 手、袖子、身体连接自然；衣服没有突然变宽；身体没有被拉伸。
- 中文文字准确；装饰符号正确；气团为正确实心白色。
- 透明背景边缘光滑；复杂背景保留完整。

> 视觉模型检查结果视为辅助判断，**不得替代用户审批**。

## 预览系统

为每个系列生成：浅色背景总览、深色背景总览、每张单独预览、必要时局部放大对比图。

预览图是检查资产，不是正式母版。生成预览时**绝不能把背景颜色烘焙进普通表情的透明 PNG**（`generate_preview.py` 通过临时合成实现）。
